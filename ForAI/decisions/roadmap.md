# 后续演进

```rag
kind: design
```

1. 增加可配置来源范围、排除规则和覆盖后缀；从整文件指纹演进为符号级证据。
2. 增量维护受影响子图，处理多工作树并发，保留可重建和幂等保证。
3. 加入游戏项目适配器：C#、C++、GDScript，以及场景/资源/项目配置引用。
4. 增加可选向量召回与语义候选抽取；所有候选有来源，不能自动升级为事实。
5. 持久化冲突生命周期与解决记录，把当前报告和历史决策分开。
6. 提供显式安装的提交检查和定时扫描集成；定时全量、开发后增量。

当前没有本地后台进程。分发仓库的 GitHub CI 在提交、PR 和每周一 UTC 01:00 检查；
采用项目的定时扫描仍需自己配置。验证优先覆盖删除、重命名、版本切换、
范围隔离、暂存区一致性及缓存重建。自然语言无冲突的证明不在系统能力承诺内。
